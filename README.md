简易记账本（expense-tracker）
一个用 Python 编写的命令行记账小工具，可以记录日常收入和支出，
自动保存数据，并支持查看全部记录与收支汇总。

功能
- 记一笔：输入类型（收入/支出）、金额、备注
- 查看全部记录：按时间列出所有账目
- 收支汇总：统计总收入、总支出和结余
- 数据自动保存在 `data.json` 文件中，下次启动自动读取

运行方法
1. 安装 Python 3（官网：https://www.python.org ）
2. 下载或克隆本仓库：

   
```bash
   git clone https://github.com/coffee-ai-123/1103.git
   cd 1103
   ```

3. 运行程序：
```bash
   python main.py
   ```

4. 按菜单提示输入数字即可使用。
运行示例

===== 简易记账本 =====
1. 记一笔
2. 查看全部记录
3. 收支汇总
0. 退出

请选择：1
类型（收入/支出）：支出
金额：25.5
备注：午饭
已保存！
```

项目结构

文件	说明	
`main.py`	主程序，包含全部功能	
`data.json`	运行后自动生成的账目数据文件
